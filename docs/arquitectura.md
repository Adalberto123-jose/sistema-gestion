# Arquitectura del sistema

Completar el diagrama cuando se elijan el lenguaje de la API y el motor de base de datos. La arquitectura mínima debe mostrar:

- Cliente que se comunica con la API, sin acceder directamente a la base de datos.
- Contenedor de aplicación/API.
- Contenedor de base de datos y red interna de Docker.
- Volumen persistente para conservar los datos.
